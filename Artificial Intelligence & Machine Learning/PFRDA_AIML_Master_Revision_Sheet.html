1. Machine Learning Foundations & Learning Paradigms

1.1 Tom Mitchell's Formal Definition of ML (1997)

"A computer program is said to learn from experience E with respect to some class of tasks T and performance measure P, if its performance at tasks in T, as measured by P, improves with experience E."
Component Definition Financial / Pension Sector Real-World Example
Task (T) The specific target problem being executed. Classifying an NPS withdrawal or insurance claim as 'Fraudulent' vs 'Legitimate'.
Performance (P) Quantitative metric measuring task effectiveness. ROC-AUC, Precision, Recall, or F1-Score of fraud detection.
Experience (E) Historical data / observations used for learning. Historical dataset of past 5 years of verified subscriber claims and transaction logs.

1.2 The Three Core Learning Paradigms

Paradigm Data Nature Learning Mechanism Primary Problem Types Key Algorithms
Supervised Learning Labelled data: pairs of input features X and target ground-truth output y. Learns a mapping function f: X → y by minimizing prediction error. Classification (discrete labels) & Regression (continuous values). Linear/Logistic Regression, Decision Trees, Random Forest, XGBoost, SVM, Naive Bayes.
Unsupervised Learning Unlabelled data: input features X only, with no target labels y. Discovers hidden patterns, clusters, density, or low-dimensional structures. Clustering, Dimensionality Reduction, Association Rules, Anomaly Detection. K-Means, K-Medoids, Hierarchical (Agglomerative), DBSCAN, PCA, t-SNE, UMAP, Apriori.
Reinforcement Learning No static dataset; sequential state-action-reward interactions. Agent learns optimal policy π(a|s) through trial-and-error to maximize cumulative discounted reward. Sequential Decision Making, Game Playing, Dynamic Control, Robotics. Q-Learning, SARSA, Deep Q-Networks (DQN), Policy Gradients, PPO, RLHF.

2. Data Preprocessing & Feature Engineering Master Reference

2.1 Missing Data Mechanisms & Imputation Strategies

Mechanism Statistical Definition Recommended Treatment Strategy
MCAR (Missing Completely at Random) Missingness is purely random, unrelated to observed or unobserved data: P(M|X, Y) = P(M). Mean/Median/Mode imputation, Complete Case Analysis (dropping rows if <5%).
MAR (Missing at Random) Missingness depends on observed features, but not on the missing value itself: P(M|X, Y) = P(M|X_observed). Multiple Imputation by Chained Equations (MICE), KNN Imputation, Predictive Modeling.
MNAR (Missing Not at Random) Missingness depends directly on the unobserved value itself (e.g. high earners hiding wealth). Add binary 'Missingness Indicator' feature; pattern-mixture models; domain-specific rules.

2.2 Outlier Detection & Treatment

  • Tukey's IQR Method: Lower Fence = Q1 - 1.5 × IQR;   Upper Fence = Q3 + 1.5 × IQR (where IQR = Q3 - Q1)
  • Z-Score Method: Z = (x - μ) / σ;   Flag as outlier if |Z| > 3.0 (assumes normal distribution)
  • Winsorization: Caps extreme values at specific percentiles (e.g. 1st and 99th percentiles) without reducing sample size.

2.3 Feature Scaling Comparison

Method Mathematical Formula Output Range / Properties Sensitivity to Outliers
Min-Max Normalization
x_norm = (x - x_min) / (x_max - x_min)
 Strictly bounded to [0, 1]. Highly Sensitive (Outliers compress normal range)
Standardization (Z-Score)
z = (x - μ) / σ
 Unbounded; Mean = 0, Variance = 1. Moderately Sensitive (Mean/Std affected by outliers)
RobustScaler
x_robust = (x - Median) / IQR
 Centered at median, scaled by interquartile range. Robust to Outliers (Ignores extreme tails)

Note: Tree-based models (Decision Trees, Random Forest, XGBoost) are inherently invariant to monotonic feature scaling. Scaling is mandatory for distance-based (KNN, K-Means, SVM) and gradient-based (Neural Networks, Logistic Regression) models.

2.4 Categorical Encoding & Imbalanced Data Handling

Technique Mechanism Key Considerations / Cautions
One-Hot Encoding Creates binary dummy column for each category. Drop 1 column (k - 1 dummies) to avoid the Dummy Variable Trap (perfect multicollinearity). High cardinality causes feature explosion.
Ordinal Encoding Maps ordered categories to integers (e.g. Low=1, Med=2, High=3). Use ONLY when natural hierarchy exists; applying to nominal categories imposes false numeric distances.
SMOTE Generates synthetic minority examples along line segments connecting k-nearest neighbors. Apply strictly to the training fold only to prevent data leakage.
Cost-Sensitive Learning Weights loss function heavily on minority errors (`class_weight='balanced'`). Penalizes False Negatives without altering underlying dataset size.

3. Model Evaluation, Cross-Validation & Error Decomposition

3.1 Confusion Matrix & Classification Metrics

Metric Formula Focus / When to Prioritize
Accuracy
Accuracy = (TP + TN) / (TP + TN + FP + FN)
 Overall correctness. Misleading in imbalanced datasets (Accuracy Paradox).
Precision (PPV)
Precision = TP / (TP + FP)
 Accuracy of positive predictions. Prioritize when False Positives are costly (e.g. spam filtering, false accusations).
Recall (Sensitivity / TPR)
Recall = TP / (TP + FN)
 Proportion of actual positives captured. Prioritize when False Negatives are dangerous (e.g. fraud, AML, disease detection).
Specificity (TNR)
Specificity = TN / (TN + FP)
 Proportion of actual negatives correctly identified. Note: False Positive Rate (FPR) = 1 - Specificity.
F1-Score
F1 = 2 × (Precision × Recall) / (Precision + Recall)
 Harmonic mean of precision and recall. Balances both; plummets if either is near zero.
ROC-AUC Area under TPR vs FPR curve across thresholds 0.5 = Random guessing; 1.0 = Perfect classifier; Threshold-independent evaluation.

3.2 Regression Evaluation Metrics

Metric Formula Characteristics
Mean Absolute Error (MAE)
MAE = (1/n) ∑ |y_i - ŷ_i|
 Linear penalty; robust to outliers; in original target units.
Root Mean Squared Error (RMSE)
RMSE = √[ (1/n) ∑ (y_i - ŷ_i)^2 ]
 Squares errors before root; heavily penalizes large outlier errors. Always RMSE ≥ MAE.
R-squared (R²)
R² = 1 - (SS_res / SS_tot)
 Fraction of variance explained. Increases automatically with added features.
Adjusted R-squared
Adj R² = 1 - [ (1 - R²)(n - 1) / (n - k - 1) ]
 Penalizes addition of uninformative features (k = number of predictors).

3.3 Bias-Variance Tradeoff

Expected Test Error = [Bias(f̂(x))]² + Var(f̂(x)) + σ_ε²   (Irreducible Error)
Property High Bias (Underfitting) High Variance (Overfitting)
Model Nature Overly simple; rigid assumptions (e.g. straight line for curved data). Overly complex; memorizes training noise and idiosyncrasies.
Error Pattern High Training Error AND High Test Error. Low Training Error, but High Test/Validation Error (Generalization Gap).
Remedies Add features, increase model complexity, reduce regularization. Add training data, apply L1/L2 regularization, prune trees, add dropout.

4. Regularization & Machine Learning Algorithms

4.1 Regularization Comparison: Lasso vs. Ridge vs. ElasticNet

Regularizer Penalty Term Added to Loss Weight Shrinkage Behavior Feature Selection?
Lasso (L1)
λ ∑ |w_j|
 Drives non-essential weights exactly to zero (sparse model). Yes (Built-in)
Ridge (L2)
λ ∑ (w_j)²
 Shrinks weights smoothly toward zero, but never exactly zero. No (Retains all features)
ElasticNet
rλ∑|w_j| + 0.5(1-r)λ∑(w_j)²
 Hybrid L1 + L2; handles groups of correlated features gracefully. Yes (Group Selection)

4.2 Ensemble Learning Architectures

Ensemble Paradigm Mechanism & Independence Primary Error Reduced Prominent Algorithms
Bagging (Bootstrap Aggregating) Trains diverse base models in parallel on random bootstrap samples (with replacement). Aggregates by voting/averaging. Reduces Variance Random Forest, Bagged Decision Trees.
Boosting Trains models sequentially; each subsequent model focuses on correcting residual errors of previous models. Reduces Bias AdaBoost, Gradient Boosting (GBM), XGBoost, LightGBM, CatBoost.
Stacking Heterogeneous base models trained in parallel; predictions used as features to train a meta-learner. Improves predictive flexibility Stacked Generalization (Level 0 learners + Level 1 meta-model).

4.3 Tree & SVM Splits Formula Reference

  • Gini Impurity (CART): Gini = 1 - ∑ (p_i)²   (Pure node = 0.0; Equal binary split = 0.50)
  • Entropy (ID3 / C4.5): H(S) = - ∑ p_i × log&sub2;(p_i)   (Pure node = 0.0; Equal binary split = 1.0)
  • SVM Soft Margin Objective: Min 0.5 ||w||² + C ∑ ξ_i   (Large C = narrow margin, low bias; Small C = wide margin, higher bias)
  • RBF Kernel: K(x, z) = exp(- γ ||x - z||²)   (Large γ = localized complex boundary; Small γ = smooth boundary)

5. Natural Language Processing (NLP) & Sentiment Analysis

5.1 Text Processing Pipeline

  1. Tokenization: Breaking sentence into words, subwords, or characters.
  2. Normalization & Case Folding: Lowercasing, punctuation stripping, unicode normalization.
  3. Stopwords Removal: Dropping common words ('is', 'the', 'at'); retain negations ('not') for sentiment!
  4. Morphology:
    • Stemming: Rule-based chopping of suffixes (Porter Stemmer); can yield non-words ('studi').
    • Lemmatization: Dictionary & POS-based morphological analysis; yields valid root lemmas ('studies' → 'study', 'better' → 'good').

5.2 Vectorization & Word Embeddings

Method Representation Nature Semantic Understanding Key Formulas / Characteristics
Bag of Words (BoW) Sparse count vector of size |V|. Zero (discards word order & grammar). Exact term frequency counts; ignores context.
TF-IDF Sparse weighted vector of size |V|. Low (lexical rarity weighting).
TF × IDF = [count(t,d)/|d|] × ln[N / (df_t + 1)]
Downweights ubiquitous words.
Word2Vec Dense continuous vector (e.g. 300d). High (semantic vector arithmetic). CBOW (context → target) vs Skip-gram (target → context). Vector('King') - Vector('Man') + Vector('Woman') ≈ Vector('Queen').
GloVe Dense vector (300d). High (global corpus co-occurrences). Log-bilinear matrix factorization on global word co-occurrence matrix.
FastText Dense subword n-gram vector. High + Morphological robustness. Decomposes words into character n-grams; handles Out-Of-Vocabulary (OOV) and misspelled words.

5.3 Sentiment Analysis Tools

  • VADER: Rule-based engine optimized for social/micro text. Uses a lexicon + grammatical rules (exclamations, capitalization, degree adverbs). Compound score: Positive ≥ +0.05, Neutral (-0.05 to +0.05), Negative ≤ -0.05.
  • FinBERT: Financial domain-adapted BERT fine-tuned on earnings calls, analyst reports, and corporate filings. Recognizes that terms like 'liability' or 'cost' are neutral balance-sheet terms rather than negative emotional sentiment.

6. Large Language Models (LLMs) & Modern Agentic AI

6.1 Transformer Architecture Archetypes

Architecture Attention Type Pre-training Objective Exemplar Models & Best Use Cases
Encoder-only Bidirectional Self-Attention (unmasked) Masked Language Modeling (MLM) BERT, RoBERTa: Classification, Named Entity Recognition, Embeddings, Extraction.
Decoder-only Causal / Autoregressive Attention (masked) Causal Language Modeling (predict next token) GPT series, Llama, Mistral: Text generation, reasoning, code generation, chatbots.
Encoder-Decoder Bidirectional Encoder + Causal Decoder Sequence-to-Sequence reconstruction Original Transformer, T5, BART: Summarization, translation, Q&A.

6.2 Fine-Tuning & Parameter-Efficient Adaptation (PEFT)

  • Full Fine-Tuning: Updates 100% of model parameters; requires immense GPU VRAM and storage.
  • LoRA (Low-Rank Adaptation): Freezes W_0, injects rank decomposition matrices: ΔW = B × A   (where r ≪ d). Reduces trainable weights by 90–99%.
  • QLoRA: Quantizes frozen base model weights to 4-bit NormalFloat (NF4), backpropagates through 16-bit LoRA adapters. Enables 70B parameter models to fine-tune on single commercial GPUs.

6.3 Retrieval-Augmented Generation (RAG) Architecture

Pipeline: Document Ingestion → Chunking with Overlap → Dense Embedding → Vector Database Indexing → Semantic Similarity Retrieval → Context-Augmented Prompting → LLM Generation
  • Mitigates: Hallucinations, knowledge cutoff dates, and lack of private/enterprise data access.
  • Advanced RAG: Hybrid search (BM25 keyword + Dense vector via RRF) and Cross-Encoder Re-ranking.

6.4 Agentic AI & ReAct Framework

Agent Component Mechanism Implementation Details
Planning & Reasoning ReAct Loop: Thought → Action → Observation Decomposes goals into sequential steps; reflects on errors; replans dynamically.
Tool / Function Calling Structured JSON Schema invocations Model outputs structured arguments to execute calculators, web search, database APIs, Python interpreters.
Memory Short-term (scratchpad) vs Long-term Context window maintains immediate working trace; Vector DB stores persistent episodic memory across sessions.

7. Reinforcement Learning (RL) & RLHF Master Summary

7.1 Markov Decision Process (MDP) Foundations

MDP 5-Tuple: (S, A, P, R, γ)  |  Bellman Optimality: Q*(s, a) = R(s, a) + γ ∑ P(s'|s,a) max_a' Q*(s', a')
Concept Role in RL Mathematical / Operational Form
Policy π(a|s) The agent's strategy / behavioral rule. Deterministic: a = π(s); Stochastic: π(a|s) = P(A_t = a | S_t = s).
Q-Function Q(s, a) Expected return taking action a from state s. Q^π(s, a) = E_π [ ∑ γ^k R_{t+k+1} | S_t = s, A_t = a ].
Q-Learning Off-policy Temporal Difference (TD) control.
Q(s, a) ← Q(s, a) + α [R + γ max_a' Q(s', a') - Q(s, a)]
SARSA On-policy Temporal Difference control.
Q(s, a) ← Q(s, a) + α [R + γ Q(s', a') - Q(s, a)]
Deep Q-Networks (DQN) Deep Q-function approximation. Experience Replay Buffer (decorrelates data) + Target Network (stabilizes moving target).

7.2 RLHF & LLM Alignment

  1. Step 1: Supervised Fine-Tuning (SFT): Train on instruction-response pairs.
  2. Step 2: Reward Model (RM) Training: Collect human pairwise preference rankings (A > B); train reward model to score outputs.
  3. Step 3: PPO Optimization: Optimize policy to maximize RM score while penalizing deviation from SFT model via KL-divergence penalty.
  4. DPO (Direct Preference Optimization): Modern alternative; optimizes policy directly on preference data without training a separate reward model or using PPO.

8. Responsible AI, Ethics & Regulatory Frameworks

8.1 Explainable AI (XAI): SHAP vs. LIME

Feature LIME (Ribeiro et al., 2016) SHAP (Lundberg & Lee, 2017)
Theoretical Foundation Local surrogate approximation (perturbation in local neighborhood). Cooperative Game Theory (Lloyd Shapley, 1953 Nobel Prize).
Explanations Provided Local only (explains single individual prediction). Both Local & Globally Consistent.
Mathematical Axioms Heuristic (no axiomatic guarantees). Satisfies Efficiency, Symmetry, Dummy/Null Player, and Additivity.
Computational Speed Fast sampling around local instance. TreeSHAP is fast; KernelSHAP is computationally intensive.

8.2 Algorithmic Fairness & Discrimination

  • Demographic Parity: P(Ŷ = 1 | A = 0) = P(Ŷ = 1 | A = 1)   (Selection rate identical across groups)
  • Equalized Odds: P(Ŷ = 1 | A=0, Y=y) = P(Ŷ = 1 | A=1, Y=y)   for y ∈ {0, 1}   (TPR and FPR identical across groups)
  • Disparate Impact vs. Disparate Treatment: Disparate Treatment is intentional use of protected traits; Disparate Impact is unintentional discriminatory outcome via correlated proxy variables (e.g. postal code, browsing history).
